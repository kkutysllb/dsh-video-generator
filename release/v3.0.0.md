## 新增

- **用途槽（Use-Slot）配置范式**：6 个槽位（`image.master` 主图 / `image.shot` 逐镜图 / `video` 视频 / `tts` 配音 / `music.bgm` 背景乐 / `music.song` MV 主曲），每槽**恰好绑定一个模型**——数据结构层无法表达第二候选，"多模型轮询/自动兜底"被类型排除。
- **槽位能力位声明**：video 槽勾 `imageToVideo`/`textToVideo`（未勾 t2v 且无参考图 → 明确失败，不找替代模型）；image 槽 `sizeParam`/`referenceImage`；tts 槽 `voice`/`instructions`；能力位缺省值显式落库。
- **通用音乐适配器（`generic-music`）**：声明式端点映射（endpoint.path / request.promptField / response.audioPath / mode；async 另需 statusPath+jobIdPath），代码零 provider 分支；同步直返与异步任务轮询两种形态；支持 base64 音频与签名 URL。
- **音乐映射模板**：4 个内置模板按**协议形态**命名（同步 URL / 同步 base64 / 异步轮询 / 异步+段落时间戳），纯数据预填、不含凭证与模型名；用户可另存/删除自己的模板。
- **槽位「测试」**：每个槽一次**真实最小调用**（图 512px / 视频 5s / TTS 一句 / 音乐 8s），结论写回 `verifiedAt/verifyNote`（成败都留痕）——落地原规格 §4.3③「按模型小额实跑验证」。
- **t2v 降级路径**：video 槽勾选 `textToVideo` 后，无参考图时自动文生视频并在 clips 事件记录 `mode:'t2v'`。
- **通道级验证留痕**：`channels.test` 写入 `verifiedAt`（连通/鉴权/枚举自检）。
- **vault v2 数据结构**：`{channels, slots, musicTemplates, budget, gateDefaults}`；`deleteChannel` 级联清除引用它的槽位绑定并返回 `clearedSlots`。
- **RPC 面**：新增 `slots.list/get/set/clear/test` 与 `musicTemplates.list/save/delete`。

## 变更

- **确认阈值真正生效**：估价未知一律确认；估价 ≤ 阈值（默认 ¥1，可改）放行；超阈值确认（旧版恒要求 confirm，阈值设置形同虚设）。
- **累计记账接线**：每次 submit 成功写 `SpendLedger`（`vgen_channels spend` 的全局 totals 不再恒 0）；记账失败不阻断生成；账本路径与 vault/runs 统一 `harnessHome` 口径（QiLin 一致）。
- **run 保留策略接线**：创建 run 时自动 `prune(50)`（旧版 prune 存在但无调用方）。
- **协议在绑定级显式声明**（`openai-images` / `openai-tts` / `dashscope-video` / `kling-video` / `openai-video` / `generic-music`），不再按模型名猜；`openai-video` 按 Sora 风格 /v1/videos 实现（真机待钉）；DashScope 提交补 `X-DashScope-Async: enable` 头（对齐附录 B.4）。
- **估价按通道**：不同槽可绑不同站点，价目表按各槽通道分别拉取。
- **设置页三区**：通道（测试不导入）/ 用途槽（六行绑定 + 测试 + 音乐模板）/ 预算与 gate；`testOk` 文案口径更新。
- **脚本直连**：`scripts/*` 经 `VGEN_IMAGE_MODEL`/`VGEN_VIDEO_MODEL`/`VGEN_TTS_MODEL` 合成槽位绑定（修复 v1.0.4 起 demo/续跑脚本因模型选择改造失效的问题）；`npm run demo:mock` 内置 mock 槽位恢复零 key 全链路。

## 修复

- **确认阈值不生效**（生产 confirmer 不读 `confirmThresholdCny`）→ `confirmSpend` 语义接线（本仓审计 A4）。
- **累计消耗恒 0**（`SpendLedger.record` 无生产调用方）→ 生成/评审重拍全部落账（审计 A3）。
- **demo/运维脚本失效**（注入通道缺 `models[]` → `model-unavailable`）→ env 槽位合成（审计 A1/A2）。
- **记账失败阻断生成**（EPERM → internal）→ `recordSafe`（不阻断，留错误日志）。
- `refreshStudio` 悬空引用、15 个 picker 时代死词典键 → 清理。

## 删除（破坏性）

- **模型池**：通道 `models[]`、`endpointProfile`、`channels.adoptModels`、`channels.setDefault`（默认通道概念取消——每槽各自选通道）。
- **枚举导入面**：设置页模型勾选面板（PickerPanel ~150 行）、`assemblePickerRowsPublic`、`inferKindByName`、`src/picker/assemble.ts`、`src/model-catalog.ts`（内置目录"按名推断形态"随之退役，迁移函数内保留一次性启发式）。
- `src/registry.ts`（`providerForModel`）→ `src/providers/protocols.ts`（`providerForSlot`，协议驱动）。

## 兼容性与升级说明

- **配置迁移**：首次加载旧 `vault.json` 自动迁移（规则见 README「通道配置」节），原文件备份 `vault.json.v1.bak-<时间戳>`；回滚 = 备份覆盖 + 装回旧版。迁移只认默认通道的 `models[]`（v1 运行时语义本就只用默认通道），其余通道模型清单在备份中。
- **行为**：未绑定槽位消费返回 `model-unavailable`（含槽位名与设置指引），确认与花费为零；`image.shot` 未绑定回落 `image.master`（唯一回落）。
- **RPC**：`channels.adoptModels` / `channels.setDefault` 调用返回 `unknown-method`；`channels.create/update` 不再接受 `models`。
- **宿主/数据**：宿主版本要求不变（0.1.5+）；runs/vault/spend 数据根不变。
- 升级方式：`dsh plugin --profile web update dsh-video-generator`（KCoder 桌面端带 `DSH_HOME=~/.kcoder`）。
