## 新增

- **漫剧工坊主面板**（侧边栏图标行，order 110，id `drama-workbench`；宿主 ≤0.1.4 无 slot 时软降级为仅设置页入口）：
  - 项目列表：工作区筛选/状态筛选/搜索、状态徽章（写作中/待审核/改编中/已完成）、章节进度、待审核数、最近任务；
  - 新建项目向导（单步表单 + 确认页）：名称/类型/语言/读者/一句话梗概/主题/基调/章节计划/创作策略；
  - 项目工作台三栏壳：阶段导航（概览/灵感前提/故事架构/世界观/角色/大纲/章节/漫剧改编/视频任务）+ 阶段工作区 + Agent/Proposal 常驻右栏；
  - 章节工作台四子视图：蓝图（手改直存）/草稿（编辑器 + 字数统计 + 另存候选稿）/审稿（结构化问题 + 待核实不算通过）/定稿（显式操作，进入连续性上下文）；
  - Proposal 审核卡片：字段级 diff（JSON）/双栏对照（Markdown）、编辑建议（应用时整体替换）、应用/拒绝留痕、过期（stale）处置；
  - 漫剧改编：选定章节 + 时长档位/画幅 9:16/侧重/旁白语言 → 一键创建改编任务并回会话发送指令，改编产物镜像回项目 + `run-link.json`；
  - 视频任务页复用 run 列表/详情（七段进度/gate/评审/花费/产物预览）。
- **项目存储**（workspace 内 `.dsh-drama/`）：JSON 资产 + Markdown 正文，版本 = 文件字节 SHA-256，读写走乐观并发（`stale-revision` 拒绝）；tmp+rename 原子写、目录 0700/文件 0600、损坏备份 `.broken-<ts>`；项目/任务/提案/改编全量落盘，跨会话恢复。
- **Host RPC 面** `/dsh-video-generator/drama`（POST JSON，{ok,value}/{ok,error} 信封，4MB 上限）：`drama.workspace.resolve / project.list|create|get / asset.get|update / proposal.list|get|apply|reject / task.create|update / adaptation.create / candidate.save|list`。
- **Agent 工具**：`drama_read`（单资产有界读取，512KiB 截断）、`drama_propose`（提案落盘，绝不直写权威文件；基线失配 → `stale-revision`）。
- **任务指令 Host 组装**：`drama.task.create` 按 kind 模板在服务端组装有限上下文（本章蓝图 + 出场角色摘要 + 相关世界观条目 + 上一章定稿末段 + 连续性事实 + 用户要求），绝不携带整本书（单测钉死）。
- **vgen_story/script/storyboard 改编联动**：携带 `workspaceId/projectId/adaptationId` 时自动镜像三段产物回项目并记录 run-link。
- **设置页「环境与诊断」**：ffmpeg/drawtext 检测、TTS 能力、产物根目录、插件版本（`diagnostics.get`）。
- 10 个新测试文件/用例组：ProjectStore、ProposalStore、drama RPC 面、drama 工具、指令组装有限上下文、bundle 契约与渲染冒烟。

## 变更

- 侧边栏与设置页导航名统一为「**漫剧工坊**」（原「视频工坊」）。
- 会话发送桥泛化为「任务指令发送」：复制指令 → `sessions.create()/open()` → `layout.selectPanel(null)` 回会话，粘贴回车即发；任务状态/事件/Session 回写 `drama.task.update`。
- 能力通告（systemPrompt section）改写为工作台 + 工具导向，新增创作纪律（先 `drama_read` 取 revision → 一次性 `drama_propose` → 用户应用前不得声称已保存）。
- 设置页轮询与工坊轮询均为 3s、`document.visibilityState` 门控，隐藏标签页零请求。

## 修复

无（功能版本）。

## 删除（破坏性）

- **插件预设退役**：`ensurePresetInstalled()` 与 `presets/`（`preset.yml` + `agent.cordis.yml`「漫剧导演」）从主流程移除——宿主已不再支持插件预设 Agent 模式。普通会话 + 能力通告即可完成全部工作流。
- 设置页不再展示 run 列表/作品库（迁往漫剧工坊「视频任务」）。
- 旧工作台主面板（题材一句话 → 创作提示词 + run 列表）被漫剧工坊替代，面板 id `vgen-panel` → `drama-workbench`。

## 兼容性与升级说明

- **破坏性**：依赖插件预设「漫剧导演」的用户需改用普通会话（能力通告自动引导）；升级后预设文件不再安装，已安装副本可手动删除 `<DSH_HOME>/.agent-presets/dsh-video-generator/`。
- **数据**：新增 `.dsh-drama/` 目录于各 workspace；既有 run 数据（`~/.dsh-video-generator/runs/` 或 `$DSH_HOME` 下）不变，历史 run 在「视频任务」顶层列表可见。
- **宿主**：需要 0.1.5+（`sidebar.panellist` + `main` keyed slot + `workspaceRegistry`）；≤0.1.4 软降级为仅设置页入口，工具不可用时返回稳定 `workspace-unknown`。
- 升级方式：`dsh plugin --profile web update dsh-video-generator`（KCoder 桌面端带 `DSH_HOME=~/.kcoder`）。
