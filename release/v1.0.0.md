## 新增

### 流水线（七段 + 断点续跑）

- 三段交接工具 `vgen_story` / `vgen_script` / `vgen_storyboard`：会话模型产出结构化
  JSON → 校验（长度/规模上限、id 正则、镜头连续性、引用完整性）→ 落盘 run 目录；
  分镜自动注入四层提示词（风格 / 运镜 / 角色锚 / 参考图提示）。
- `vgen_generate`（assets → video → final 推进）+ `vgen_status`（进度 / gates / reviews /
  最近事件）：run.json 即事实源，落盘原子写（0700/0600），断点续跑已完成段不重花钱，
  最近 50 个 run 自动清理。
- 单镜生成序列（submit → 轮询 → 拉片 → 落盘）抽出 `shot-clip.ts`，流水线 video 段与
  评审重拍共用；瞬态错误（网络 / 429 / 5xx）自动退避重试。
- 成片链：timeline 微秒线性模型 → ffmpeg 归一化（覆盖式缩放 + 中心 crop 消黑边）→
  concat → drawtext 字幕 → 双通道混音，产出 1080×1920 mp4 + SRT。
- 配音链：云端 TTS（OpenAI 兼容 `/v1/audio/speech`，支持语气指令）优先，
  本地 say（macOS）/ SAPI（Windows）兜底，无配音事件留痕。

### 质量评审闭环

- `vgen_review`：阶段A 抽成片 25/50/75% 三帧返回路径；阶段B 携带 score（1-5，
  越界 clamp、非法兜底不重拍）——≥3 记通过，≤2 自动追加负面词重拍（每镜 ≤2 次，
  花费走 confirm 语义），重拍失败无条件回滚旧片并留痕，重拍后自动重新抽帧闭环。

### gate 三态真实现（规格 §5.2）

- 每段 `auto / ask / manual`：ask 经 `gateApprovals` 会话放行（`gate-approval` 信封指引）；
  manual 经 `vgen_provide` 产物注入——master-asset（char-*/scene-* 命名校验）、
  shot-assets（逐镜 + 公网 URL 警示）、video（storyboard 全镜覆盖 + 时长 ≥0.5s）、
  final-cut（.mp4 注入即整 run done）；gate 覆盖持久化进 run.json，
  `rerunStage` 可重置媒体段重跑。

### 通道与成本护栏

- 多通道三要素保险库（0700/0600 原子写、全出口脱敏、https 强制）、两层模型目录
  （内置模式匹配 + 用户覆盖）、通道探测（/models 枚举 + 鉴权）、站点价目表估价、
  单笔确认阈值（unknown 价一律确认）、SpendLedger 记账。
- `vgen_channels`：`list` 脱敏面板 / `health` 探测健康 + 估价 / `spend` 累计消耗。
- `VGEN_VIDEO_MODEL` 环境变量：video 段与重拍换档（上游分组饱和时切换模型组）。

### 设置页（Web 设置 →「视频工坊」，双 tab）

- 手写自注册 client bundle（零构建依赖、宿主注入 react）：**工坊**（run 列表 / 阶段
  chips / gate 与评审徽章 / 产物预览 / 花费行，3s 轮询仅页面可见时运转）+
  **通道管理**（三要素表单、提交即清空、只回显脱敏串、测试通道、枚举模型一键导入、
  默认通道、预算阈值、gate 缺省）。
- host 新增路由：`GET /runs/<id>`（详情 + 产物清单）、`GET /media/<runId>/<rel>`
  （产物流式预览：穿越三层防线 + loopback 围栏 + no-store）、`GET /channels` 与
  `POST /settings` 便捷入口；`/api/channels.adoptModels` 按内置目录推断 kind
  （unknown 不覆盖用户已配置 kind）。

### Agent 预设与运维脚本

- 「漫剧导演」预设（加载时幂等安装 `~/.dsh` 与 `~/.kcoder` 双候选目录），
  内置「疗愈绘本」题材包（风格词汇 / 角色原型 / 节奏模板 / 负面词 / 运镜基调）。
- `scripts/demo-mock.ts` 零 key 全链路 demo（lavfi 占位片 + mock URL 本地供流，
  含评审重拍闭环）；`scripts/demo-drama.ts` 真机三镜出片 + 评审抽帧；
  `scripts/resume-video.ts` 饱和挂账断点续跑；`scripts/live-routes.ts` 路由真机冒烟。
- 适配器：OpenAI 兼容图像（同步 URL 短路）、DashScope 中转（异步任务 + 轮询）、
  kling-compat、mock 全链路；轮询超时即失败（不记成功）。

## 变更

- **画幅策略**：参考图统一竖版生成（`1024x1536`，2:3 最接近竖档），渲染归一化从
  `scale=decrease + pad` 改为 `scale=increase + crop`——消除 9:16 画布黑边；
  画布宽高须为偶数（libx264 yuv420p 约束，已注释钉住）。
- **demo 成本确认收紧**：非交互终端必须显式 `VGEN_AUTO_CONFIRM=1` 才放行花费
  （此前非 TTY 自动确认过于激进）；交互终端逐笔询问不变。
- 图像提交透传 `size` 参数，服务端 400 单次降级重提（`size-fallback` 事件留痕）。
- 图像 / 视频提交包 `retryTransient`（网络 / 429 / ≥500 退避重试），下载 120s 超时。
- 工具面 8 个（规格 §7.1 为 7 个）：manual gate 产物注入需要独立入口 `vgen_provide`
  （偏离说明见 README）。

## 修复

- **成片 5 秒后无声**：音频链 `adelay` 在 `atrim` 之前——裁剪把延迟后的语音裁成了
  静音。改为 `atrim` 先行 + `adelay=delays=N:all=1`，回归断言钉死 filter 顺序。
- **配音生硬不连贯**：本地 say 紧凑音色机械感强。接入云端 TTS 通道（语气指令
  「温柔的中文女声旁白」），同句时长从 ~2.5-3.6s 放缓到 3.0-3.9s，失败自动回退本地。
- **通道配置静默覆盖**：vault 去掉数据缓存，mutate 一律 load→fn→save，杜绝旧缓存
  回写覆盖新配置。
- **信任围栏绕过**：`127.0.0.1.evil.com` 前缀形态 + remote 兜底互补可被伪造 Host
  绕过——重写为 WHATWG URL 解析精确匹配，Host 存在即权威、与 remote 绝不互补，
  重复 Host 直接拒绝。
- **媒体路由穿越**：`/media` 段级拒绝 `.`/`..`/空段 + 防御性二次 decode（双编码形态）
  + resolve 前缀核验，纯函数逐例测试钉死。
- **adoptModels 盲覆盖**：目录不认识的名字（unknown 缺省 video）不再覆盖用户已配置
  的模型 kind；video 段产物注入改为先全验后拷，校验失败不留半套残留。

## 兼容性与升级说明

- **运行环境**：Node ≥ 24（strip-types 直跑测试）；成片链路依赖本机 ffmpeg 且须含
  `drawtext` 滤镜（Homebrew 精简构建常见缺失，用 `VGEN_FFMPEG` 指向完整构建，
  如 bilibili 客户端自带版）。
- **通道契约**：`baseUrl` = 站点根（不带 `/v1` 后缀；OpenAI 兼容端点由插件自动拼接）；
  强制 https（本地调试可 `VGEN_ALLOW_INSECURE=1`）。
- **已知限制**：手动提供的 shot 参考图无公网 URL → video 段自动 i2v 不可用；
  kling-compat 信封未真机钉契约；Windows SAPI 未真机验证；happyhorse 等免费档模型
  可能带平台水印。
- **升级**：无前序公开版本，直接安装。
