## 新增

- **漫剧工坊功能六项**（规格对照表 2026-10-04 拍板）：
  - 项目卡片「最近成片」（最近改编 run 状态摘要）；
  - Agent 面板「成本/风险提示」（最近 run 花费汇总 + 失败风险 chip）；
  - 提案「重新生成」按钮（diff 视图 + stale 卡片，按 assetRef 推导同 kind 任务重新发起）；
  - 指令「重试发送」（create/instruction 双模式：不重复建任务、已发指令不重复发）；
  - 运行中任务「会话已中断，可继续」提示 + [重发指令]（指令随任务持久化，仅重发不重建）；
  - 蓝图「需承接的上一章事实自动带出」双通道：`generate-chapter-blueprint` 指令携带上一章定稿末段 + 连续性事实 + 承接指引；页面打开蓝图表单时上一章 `newFacts` 自动预填（字段为空才预填，保存才落盘）。
- **大纲/角色整库提案 diff 逐条目高亮**：`flattenRows` 重写为递归展开（数组按索引、对象逐字段）。
- **角色列表**：字母头像占位 + `hasVisualAsset`「视觉」角标（详情表单可编辑）。
- **音乐模板删除 UI**：设置页音乐槽新增「删除模板…」（此前仅 RPC 无入口，规格 §4.2 user 模板可删除约束落地）。
- **CI**：GitHub Actions（node 24 + typecheck + test + ubuntu ffmpeg/drawtext/CJK 字体 + demo:mock 零 key 全链路硬门槛）。
- **哨兵测试扩面**（`test/lib-hygiene.test.ts` + `test/slot-probe.test.ts`）：lib 孤儿构建残留、picker 旧符号防回流、`route()` 防回流、dependencies 为空、provider 名静态断言扩面（providers+pipeline 全量剥注释扫描）、`testSlotBinding` 离线单测（成功/401/通道缺失）。

## 变更

- **漫剧工坊 UI 对齐宿主插件风格**（自动化任务/动效技能配方）：铺满面板宽度（去 1080px 限宽居中），补缺失的 `.vg-wb-grid` 规则（项目卡片改自适应网格）；全部颜色走宿主 `--dsw-alias-*` 令牌（明暗主题随壳层）；徽章/chip 改 999px 胶囊 + color-mix 铺底；按钮三档规范化；面板根元素自带滚动（`height:100%+overflow:auto`）。
- **能力通告与工具枚举补 `music`**：`vgenGuidance` 与 `vgen_generate` 的 `target`/`rerunStage` 枚举补 `'music'`（此前会话模型拿不到 music 段的合法入口）。
- **music 段断点续跑**：submit 留痕 `music-job` / 上游终态 failed 记 `music-job-dead`；重推续查同一 jobId（`music-resume`），超时/取消后重跑**不重复提交、不重复计费**；轮询上限 600s→480s（给 submit/下载/分析留工具窗口头寸）。
- **取消感知轮询**：`pollUntil` 支持 abort 信号（sleep 即停），music/video 轮询中止转宿主停用语义（`run-interrupted`），不再误报任务失败。
- **蓝图/记账事件**：run 内 5 处 `spend` 事件补 `channel` 字段；`bgm-mix` 事件如实记录实际混入文件（MV 模式此前硬编码 bgm.mp3）。

## 修复

- **面板无法滚动**（v2.1.0 引入的回归）：工坊页面改 flex 布局时漏掉根元素自滚层，长内容被裁；补 `height:100%/min-height:0/overflow:auto`（kyl-panel 配方）。
- **hero 图标白底白字**：图标 tile 改宿主品牌令牌后，暗色白胶囊主题下白色描边隐形；改 `currentColor` 跟随配对前景令牌。
- **指令发送 result=none 误报成功**：复制失败时曾提示「已复制」，改为失败文案 + 可重试。
- **歌词契约**（规格 §6.2）：14 段落标签白名单校验（`[Random]`/无标签拒收，容忍 `[Verse 1]` 序号后缀）；MV 模式 song 槽无歌词 → 确认之前抛 `bad-request`（零花费）。
- **死代码清理**：`route()` 能力路由（规格 §8 删除清单收口）；dashscope 适配器移除 `model.includes('i2v')` 模型名猜测（i2v 一律能力位声明）；12 个死词典键（v1.x 视频工坊 tab 残留 + 未实现的 doRegenerate）。
- **测试卫生**：review 重拍用例记账泄漏真实 `~/.dsh-video-generator/spend.jsonl`（84 条夹具数据）——测试注入隔离 `DSH_HOME`。
