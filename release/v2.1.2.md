## 新增

- **任务删除入口**（用户反馈：卡住的未完成任务无法清除，没法重新开始）：Agent 面板「当前任务」新增「删除任务」按钮（红色，确认弹窗后不可恢复）；新增 `drama.task.delete` RPC + store `deleteTask`。删除任务记录后可重新发起同任务；已发起的生成不会自动终止（提示语明示，费用不退）。关联 run 与改编记录不受影响。
- **媒体段条目级断点续跑事件**：master-asset / shot-assets 每个付费条目完成即落 `asset-item` 事件（含 stage/key/file/url）；`rerunStage` 显式重做落 `stage-redo` 事件（旧条目作废）。与 v2.1.1 music 段 `music-job` 留痕同一模式，规格 §5.1「已完成段不重花钱」覆盖到全部图像段。

## 变更

- **续跑语义分化（对会话模型的行为指引）**：
  - **直接重推**（不带 `rerunStage`）＝续跑：段中途失败/掐断后重推，已付费且产物在盘的条目自动跳过，只补漏的条目（不再重复提交、不再重复计费）；
  - **`rerunStage`＝点名全量重做**：旧条目全部作废、重新计费（参考图过期等确需重生成时用）。
  - 同步更新三处 Agent 指引文案：`vgen_generate` 的 `rerunStage` 参数描述、host-interrupted 错误消息（原来教模型「用 rerunStage 续跑」→ 改为「直接重推即条目级续跑」）、`vgenGuidance` 工作流速记。
- **分镜校验宽容化**：`characterIds` 接受逗号/顿号/空白分隔的字符串形态（自动拆分）；未命中引用依次尝试大小写不敏感 id → 唯一角色名映射（Agent 传 `"LinJing"` 或 `"林鲸"` 均归一到 `linjing`）。

## 修复

- **vgen_storyboard 的 characterIds 校验误拒**（用户实测反馈）：字符串形态被硬拒（「须为数组」），传角色名/大小写不符的 id 报「引用不存在的角色」但**不列出有效 id**，Agent 瞎猜失败后只能省略字段绕过提交（丢失角色一致性锚点）。根因：`strArray` 只认数组 + 引用校验只做精确 id 匹配。修后：三种形态（数组/字符串/省略）全通；报错消息**列出全部有效角色 id**（「引用不存在的角色: X（有效 id：alice、bob）」），一次修正不再猜。
- **master-asset 段 600s 工具窗口掐断后重跑重复扣费**（用户实测反馈）：段内泵对已付费条目无记忆，中途失败后重推全量重做。根因：master-asset/shot-assets 段只有段级状态机，无条目级留痕（video/music 有）。修后：条目完成即留痕 `asset-item`，重推按 key（`char:<id>`/`scene:<id>`/`shot:<index>`）跳过已完成条目；shot-assets 重推补漏后最终 `shot-urls` 事件仍为全量（video 段 i2v 输入不缺镜）。跳过前校验产物文件在盘（产物被清理的条目照常重做）。

## 兼容性与升级说明

- **无破坏性变更**：vault 结构不变；工具入参/错误码向后兼容；新增 `asset-item`/`stage-redo` 事件类型与 `drama.task.delete` RPC 面（消费者按未知类型/未知方法忽略即可）。
- **行为语义提示**：`rerunStage` 现在意味着「全量重做、重新计费」——中断续跑请直接重推。手动把 run.json 段状态改回 `pending` 属续跑（不重做已付费条目）；确需全量重生成用 `rerunStage`。
- 升级方式：KCoder/DSH 插件管理检测到新版本后手动更新；数据无需迁移。
