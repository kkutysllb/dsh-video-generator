# v2.1.3 —— 兼容门左支上界扩至 `<1.0.0`（dsh 0.2.1-alpha.1 修复）

## 版本信息

- **版本号**：2.1.3（package.json / PLUGIN_VERSION 同步）
- **日期**：2026-10-04
- **tag**：`v2.1.3`
- **主题**：peer 兼容门修正——左支上界 `<0.2.0` → `<1.0.0`；右支 QiLin 3.x **保留不动**
- **发布渠道**：npm（v2.1.2 已发布）

## 变更

- **修复：dsh `0.2.1-alpha.1` 下插件被兼容门静默禁用**：
  - **现象**：升级到上游 `dsh-v0.2.1-alpha.1`（2026-10-03 prerelease）后插件不再加载，
    宿主 stderr 仅一行 `disabling profile plugin …`，界面无提示。
  - **根因**：7 条 `peerDependencies` 左支上界 `<0.2.0` 对运行时 `0.2.1-alpha.1`
    求值为 **false**。该支定义于 0.1.7 世代，仅在 `0.2.0-rc.*` 下侥幸成立
    （semver 里 `0.2.0-rc.2 < 0.2.0`），上游跨过 `0.2.0` 边界即失配。
    宿主检查器只读 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-*` 前缀的 peer，
    按 `semver.satisfies(..., { includePrerelease: true })` 评估。
  - **修复**：左支上界统一改为 **`<1.0.0`**，即
    `>=0.1.0-rc.5 <1.0.0 || >=3.0.0 <4.0.0`。
- **右支 `>=3.0.0 <4.0.0` 原样保留**：该支是 v2.0.2 为 QiLin 3.x 运行时号预留的
  （见 [v2.0.2](v2.0.2.md)），**不做任何收窄**——本次只放宽左支上界。
- `peerDependenciesMeta` 保持**全部 optional**（防 pnpm 把整棵引擎树拉进用户 profile）。

## 兼容性

- **放宽是向后兼容的**：旧左支覆盖的 `0.1.0-rc.5` → `0.2.0-rc.2` 仍在新左支内，
  现网 KCoder（0.2.0-rc.2）行为不变；QiLin 侧由右支继续覆盖；
- 纯声明层改动：仅 `package.json` 的 7 条 peer 范围、`PLUGIN_VERSION`（强同源）
  与契约哨兵期望值；`lib/**`、管线、路由、UI 全部不变；
- 升级即替换包体，无需迁移。
