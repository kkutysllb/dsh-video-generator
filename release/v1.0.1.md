## 变更

- **预设安装目标改为跟随 harness home**（`<DSH_HOME>/.agent-presets/dsh-video-generator/`）：
  `DSH_HOME` 环境变量优先，未设回退用户主目录——与插件 vault/runs 的解析语义一致，
  也与宿主 launcher 的 home 解析一致。KCoder 等品牌部署由其启动器注入自己的
  `DSH_HOME`（如 `~/.kcoder`），任何自定义 home 均被正确跟随；禁止写死任何品牌目录。
  新增回归测试：`DSH_HOME` 下不得出现 `.dsh`/`.kcoder` 品牌层。
- README / 发布说明中的预设路径描述同步为新语义。

## 修复

- **症状**：预设被安装到写死的 `~/.dsh/.agent-presets/` 与 `~/.kcoder/.agent-presets/`
  双目录；`DSH_HOME` 指向其他 harness home 的部署（自定义目录、第三方品牌）装不上
  预设「漫剧导演」。
- **根因**：安装目标按品牌目录名硬编码，未跟随宿主 `DSH_HOME` 解析。
- **修后行为**：安装目标 = `DSH_HOME ?? homedir()` 下的 `.agent-presets/dsh-video-generator/`，
  与宿主预设发现面（`<harnessHome>/.agent-presets/`）严格一致。
