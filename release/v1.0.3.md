# v1.0.3（2026-09-08）

修复：上游 dsh-persona loader schema 升级（`prefix` 字段必填）后，preset `agent.cordis.yml`
使用 `text:` 字段被 schemastery 拒绝，导致切换「漫剧导演」preset 失败
（错误：`invalid config: $.prefix missing required value`）。

## 修复

- **症状**：在 KCoder GUI 切换到「漫剧导演」preset 失败，报
  `failed to apply loader entry persona (@deepseek-ai/dsh-persona): invalid config: - $.prefix missing required value`。
- **根因**：`presets/agent.cordis.yml` 的 persona row config 用 `text:` 字段，但
  `@deepseek-ai/dsh-persona/lib/index.js` 的 `Config` schema 收 `prefix: string (required)`。
  上游升级 schema 时未做兼容 shim，未迁移的 preset 全部失效。
- **修后行为**：persona config `text:` → `prefix:` + 加 schema 注释钉住必填字段名，
  避免后人误改字段名。
- 同型 bug 影响 dsh-super-ppts、dsh-animations 三个插件 preset —— 同期修复并各自发版。

## 兼容性与升级说明

- 无后端 / 客户端 / API 破坏性变化；仅 preset YAML 字段名修正。
- 升级方式：`dsh plugin --profile web add dsh-video-generator`（插件管理检测到新版本后手动更新）。
- 既有「漫剧导演」preset 切换在升级后即可生效（无需重装插件）。
